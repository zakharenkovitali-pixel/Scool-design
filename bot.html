Конфигурация

ПеременнаяСтатус
TELEGRAM_BOT_TOKENВ .env пусто
TELEGRAM_CHANNEL_IDНе задан
TELEGRAM_OWNER_CHAT_IDНе задан
VERCEL_TOKENИспользуется CLI-логин

Запуск

# 1. Скопировать пример переменных и заполнить токеном от @BotFather
$ cp .env.example .env

# 2. DRY-RUN (без реального бота): пишет транскрипт в outputs/bot_runs/sample_session.md
$ npm run bot

# 3. После того как TELEGRAM_BOT_TOKEN заполнен — runLive() поднимет реальный бот
$ npm run bot

Отправка персональных КП клиентам

Скопируйте ссылку и отправьте клиенту в Telegram, WhatsApp, SMS или email. Когда клиент кликнет — бот узнает его, поприветствует по имени и пришлёт URL персонального КП на Vercel. Каждый клик дополнительно уведомляет владельца студии в личку.

КлиентОбъектDeep-linkПрямой КП
Юлия · lead-001 3-комнатная квартира · Park Towers https://t.me/desind_school_vtg_bot?start=lead-001 /offer/lead-001
Карина · lead-003 студия · Самолёт https://t.me/desind_school_vtg_bot?start=lead-003 /offer/lead-003
Артём · lead-002 дом · Европея https://t.me/desind_school_vtg_bot?start=lead-002 /offer/lead-002
Игорь · lead-004 коммерческое помещение, кофейня · — https://t.me/desind_school_vtg_bot?start=lead-004 /offer/lead-004

Команда для владельца в боте: /kp lead-001 — пришлёт ссылку на КП в текущий чат, без обращения по имени.
